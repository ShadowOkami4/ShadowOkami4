## About

I'm Okami, a hobby developer who likes turning personal ideas into useful
tools, experiments, long-term projects and worlds to explore. I build for my
own setup and interests first, then share the results publicly when they
become useful, interesting or simply fun for others too.

I work at my own pace, try new technologies, and shape each project around
how I would actually use, play or explore it.

> [!NOTE]
> **On AI-assisted development.** I use AI coding assistants (LLMs) as a tool
> when I need them, to learn new languages and technologies faster and to get
> ideas built sooner. I review, test and use everything I publish, and my goal
> is to understand and improve every part of my projects myself over time.
> Each repository says how it was made, so you always know what to expect.
